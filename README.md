Интернет-магазин дизайнерской мебели, декора и текстиля на Django, доступный по адресу **[feralcraft.store](https://feralcraft.store/)**.

## 🪑 О проекте

**FERAL & CRAFT** - веб-приложение для продажи мебели, реализующее полный цикл онлайн-магазина: от просмотра каталога до оплаты заказа. Проект построен на Django и разделён на независимые приложения (apps), каждое из которых отвечает за свою область ответственности.

## ✨ Возможности

| Модуль | Приложение | Назначение |
|---|---|---|
| 🏠 Главная | `main` | Промо-блоки: скидки, подборки по стилю, преимущества компании |
| 📖 О компании | `main` | Страница с ценностями бренда и статистикой (заказы, филиалы, качество) |
| 🗂 Каталог | `main` | Список товаров с фильтром по категориям (сайдбар) и постраничной навигацией |
| 🖼 Карточка товара | `main` | Галерея изображений товара (переключение стрелками), цена/скидка, форма добавления в корзину |
| 📰 Новости | `news` | Блог / новостной раздел магазина |
| 🛒 Корзина | `cart` | Корзина покупок на основе сессий, доступна на всех страницах сайта |
| 👤 Пользователи | `users` | Регистрация, вход, личный кабинет |
| 📦 Заказы | `orders` | Оформление и учёт заказов |
| 💳 Оплата | `payment` | Онлайн-оплата через Stripe Checkout |

### Как работает оплата

1. Пользователь оформляет заказ и переходит на страницу оплаты, где видит список товаров заказа.
2. По нажатию «Pay now» бэкенд создаёт Stripe Checkout Session с ценами и количеством товаров из заказа.
3. Пользователь перенаправляется на защищённую страницу оплаты Stripe.
4. После оплаты Stripe вызывает webhook, который проверяет подпись запроса и, если платёж прошёл успешно, отмечает заказ как оплаченный и сохраняет идентификатор платежа.
5. Пользователя перенаправляет на страницу успешной оплаты или отмены.

## 🛠 Стек технологий

- **Backend:** Python, Django 5.2
- **База данных:** PostgreSQL
- **Оплата:** Stripe API (Checkout Session + webhooks)
- **Frontend:** Django-шаблоны, Bootstrap, кастомные стили, Google Fonts (IBM Plex Serif), vanilla JS
- **Конфигурация:** python-dotenv

## 📁 Структура проекта

```

├── furniture_store/       # настройки проекта (settings, urls, wsgi, asgi)

├── users/                 # пользователи и аутентификация

├── static/                # статические файлы
├── media/                 # изображения товаров
└── manage.py
```

## 🚀 Установка и запуск

```bash
git clone https://github.com/AliceTaran/furniture_store.git
cd furniture_store

python -m venv venv
source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Сайт будет доступен по адресу `http://127.0.0.1:8000/`.

## 🔒 Безопасность

- Кастомная модель пользователя (`AUTH_USER_MODEL = 'users.User'`).
- `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE` и `SECURE_SSL_REDIRECT` включены для защищённой работы по HTTPS.
- Секретные ключи и пароль базы данных хранятся в `.env` и не попадают в систему контроля версий.
